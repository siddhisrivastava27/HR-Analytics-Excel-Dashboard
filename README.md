# 📊 HR Analytics Dashboard | Excel

## Project Overview

This project focuses on analyzing employee data to understand workforce distribution, compensation patterns, employee performance categories, overtime trends, and employee attrition.

Using Microsoft Excel, I cleaned and organized raw HR data, created calculated columns using Excel functions, developed PivotTables, and built an interactive dashboard with slicers and charts to present key HR metrics in a clear and meaningful way.

The goal of this project is to transform raw employee data into useful insights that can support HR reporting and workforce analysis.

##  Project Objectives

- Analyze the overall workforce and employee distribution.
- Evaluate employee compensation and monthly income patterns.
- Understand overtime distribution among employees.
- Explore employee distribution across job roles and years at the company.
- Categorize employees based on income, performance, and employment status.
- Analyze employee attrition and explore workforce trends.
- Build an interactive dashboard for easier data exploration.

##  Data Cleaning & Preparation

The project began with raw employee data, which I cleaned and organized to prepare it for analysis.

Key tasks included:

- Preparing a cleaned version of the raw dataset.
- Creating additional calculated columns using Excel's IF function.
- Organizing data for PivotTable analysis.
- Preparing the dataset for dashboard visualizations and KPI calculations.

### Additional Columns Created

| Column | Purpose |
|---|---|
| Income Category | Categorizes employees based on monthly income. |
| Performance Category | Groups employees into performance categories based on the defined conditions. |
| Employee Status | Classifies employees based on the conditions defined in the formula. |
| Monthly Rate | Adds a calculated numeric field using an Excel formula. |

## Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard includes the following key metrics:

- **Total Employees** — Overall employee count.
- **Total Monthly Income** — Combined monthly income across employees.
- **Average Monthly Income** — Average monthly income per employee.
- **Overtime Employees** — Number of employees working overtime.

### 2. Interactive Filters

The dashboard includes slicers for:

- Career Stage
- Job Level
- Gender (Female and Male)

These slicers allow users to filter the dashboard and explore workforce metrics across different employee groups.

### 3. Charts & Visualizations

The dashboard contains visualizations covering:

- Overtime Distribution
- Employees by Job Role
- Employee Count by Selected Categories
- Employee Distribution by Years at Company
- Average Monthly Income

These visualizations help explore workforce composition, overtime patterns, compensation, and employee experience.
